# Majora's Mask 3D: Project Restoration

Official Project Restoration 1.5.9, v110/citra, for US title 0004000000125500. The patch source and output CRC32 were verified against the supplied decrypted US revision 1 executable.

Install the two files in mods/0004000000125500/ into the emulator's game modifications directory. code.bps patches the decompressed game executable; it is not a whole-cartridge patch.

The browser Azahar experiment still has rendering failures. This package is not an active or verified-playable Apollo game. The supplied 1 GiB cartridge is prepared locally as 52 parts and is not included in this mod package.

Source and installation instructions: https://restoration.zora.re/
Release: https://github.com/leoetlino/project-restoration/releases/tag/v1.5.9
